Run it yourself

Everything on this page can be re-checked with the package. With Docker (Macaulay2 1.22, the package and an MCP server in one image):

git clone https://github.com/timseifer/HodgeLociCI && cd HodgeLociCI
docker build -t hodgelocici .
docker run --rm hodgelocici                    # quickstart, compared with its expected output
docker run --rm hodgelocici tests/run_all.sh   # validation suite

For AI assistants, an MCP server with the tools excess_formula, second_order_check, fermat_expansion and registry_search (every output carries its status label): docker run --rm -i hodgelocici python -m hodgelocici_mcp. Setup for Claude Desktop and Claude Code: mcp/README.md; without Docker: installation. Cite: doi:10.5281/zenodo.24455334.
