# Session scripts behind the cubic tenfold lead (copied as-is, 25 Nov 2026)

AI-written research scripts (Macaulay2, Python, C++, shell) from the sessions that produced registry entries
O-TENFOLD-CONE-LEAD, N-TENFOLD-CODIM54-SEARCH, N-TENFOLD-CODIM54-SEARCH-2, N-TENFOLD-DIRECT-METHODS and
D-TENFOLD-LAMBDA0-CHECK. Unreviewed; not part of the package; not covered by CI. They contain absolute paths from
the original machine (`/home/claude/...`, e.g. `/home/claude/hodgelocici/M2/HodgeLociCI.m2` = this repository's
`M2/HodgeLociCI.m2`): adjust them before running. Outputs, logs and large data files are not included.

Directories match the session-ledger tags (see leads/TENFOLD_HANDOFF.md, section 6): w1-w4, ex_t6, exp_t6, bc_t6,
nf_t6, rc_t6, da_t6, sp_t6 (Fermat point and cone locus); ts_t6, bc_ts (split points); so_t6, bc_so (order 2 at
F_T); so3_t6, bc_so3 (order 3); sr_t6 (semiregularity); dp_t6 (del Pezzo points); cs_t6, cs_t6d, cs2_t6, cs3_m1,
cs3_m2 (construction searches, direct methods; cs3_m2/adm.txt = admissible invariants); ss_t6 (singular sections);
rs5 (reproduction of rStation #5's sixfold monomial directions).
