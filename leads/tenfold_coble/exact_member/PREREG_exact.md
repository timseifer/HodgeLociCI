# An exact member: pre-registration (written 25 Nov 2026, night, before any run of the scripts named here)

## Aim
One named smooth cubic tenfold X over QQ in the Coble family, with a certificate over QQ for:
  (X1) X is smooth;
  (X2) Sigma = Sing(X ∩ P^8) ∩ {Phi_0 = Phi_1 = 0} is 72 distinct points;
  (X3) the hyperplane section X' = X ∩ {w_2 = 0} has exactly these 72 singular points and they are ordinary double points;
  (X4) the 72 points impose exactly 71 conditions on quartics;
  (X5) Phi_2 does not vanish on Sigma.
Given (X1)-(X5), the statement "X carries a rational Hodge class that is not a multiple of h^5" follows from two cited
theorems and one argument, none of which is computed here: Dimca's formula for the tenth Betti number of a nodal
9-fold (LIT), purity and type (5,5) of the extra class (ARG), injectivity of H_10(X') -> H_10(X) (ARG; Thom isotopy as
in section 10.3 of the lead note, or Siersma-Tibar, LIT). The class is moreover algebraic by section 10 (ARG).
This is NOT a statement about the Hodge conjecture and the class is not "not known to be algebraic".

## The member (fixed rule; the choice is made by the rule, not by me)
Variables z_0..z_2, p_0..p_2, q_0..q_2, w_0..w_2; y = (z,p,q). x = (4,3,3), lam = 3, a = -221/378 (the member that
D-TENFOLD-COBLE-FAMILY already treats over QQ). With h(v) = v0^3 + v1^3 + v2^3 + 9 v0 v1 v2 and
M(z,p,q) = sum_{i,j} x_{(i-j) mod 3} z_{(i+j) mod 3} p_i q_j:
    F8 = -221 h(z) + 378 h(p) + 378 h(q) + 378 M(z,p,q)                      (= 378 F#)
    F  = F8 + w_0 Phi_0(y) + w_1 Phi_1(y) + w_2 Phi_2(y) + Wpart(w, y).
Phi_k for candidate c = 1, 2, 3, ...: Python random.Random(1000 + c); for k = 0, 1, 2 in turn: 6 distinct monomials
drawn from the 45 quadratic monomials in y (random.sample on the list in lexicographic order of exponent vectors),
each with a coefficient random.choice([-2,-1,1,2]).  Wpart options, in this order:
    W1 = w_0^3 + w_1^3 + w_2^3;      W2 = W1 + w_0^2 z_0 + w_1^2 p_1 + w_2^2 q_2.
Selection: the first (c, W) in the order (1,W1), (1,W2), (2,W1), (2,W2), ... that passes this screening MOD 32003:
(s1) Sigma has dimension 0, degree 72, 72 distinct points; (s2) Sing(Y) ∩ {Phi_0=Phi_1=Phi_2=0} is empty;
(s3) the Jacobian ideal of F in 12 variables has no projective zero; (s4) the Jacobian scheme of F|_{w_2=0} in P^10
has dimension 0 and degree 72. Candidates that fail are recorded with the reason. Screening is selection, not evidence.

## The certificate and how each item becomes a statement over QQ
All ideals are generated by polynomials with integer coefficients; p is a prime not dividing 2*3*7*13*17 (378 = 2*27*7,
221 = 13*17) and the reductions below are of those integer generators.
 (X1) empty singular locus mod one such p  =>  empty over QQ (the singular scheme is proper over Z_(p); a closed subset
      of Spec Z_(p) containing the generic point contains the closed point).
 (X2) degree: computed over QQ directly (dimension 0, degree 72 of the scheme defined by the nine partials of F8 and
      Phi_0, Phi_1). Distinct points: the scheme over Z_(p) is then finite and flat (length 72 at both points), its
      special fibre is etale (squarefree projection to a line of degree 72 mod p), so the generic fibre is etale.
 (X3) the Jacobian scheme of F' = F|_{w_2=0} mod p has dimension 0 and length 72  =>  over QQ it is finite of length
      <= 72 (fibre dimension and, for a finite scheme over a DVR, length are upper semicontinuous). It contains Sigma
      (the partials of F' restricted to w = 0 are the partials of F8 and Phi_0, Phi_1), of length 72 by (X2). So the two
      are equal: 72 reduced singular points, Tjurina number 1 each, hence ordinary double points; none elsewhere.
 (X4) lower bound: for the flat family Sigma over Z_(p), h^0(I_Sigma(4)) can only go up at the special fibre, so the
      Hilbert function in degree 4 over QQ is >= the one mod p (71 predicted).  Upper bound: for ANY ideal I with
      integer generators contained in the ideal of Sigma, dim_QQ I_4 >= dim_{F_p} (I mod p)_4 (rank of an integer matrix),
      so HF_QQ(4) <= 495 - dim_{F_p}(I mod p)_4. I = (partials of F8, three more integer cubics of the saturation if
      needed, Phi_0, Phi_1); if this gives 71 the item is closed; if not, compute the saturation over QQ directly.
 (X5) empty mod p => empty over QQ, as in (X1).
Where a direct computation over QQ finishes in reasonable time (limit 40 minutes each) it is done as well and reported
as EXACT; otherwise the item rests on "MOD p plus the specialization argument above" and is labelled so.

## Outcomes
 - all five hold: the member is recorded with its equation; status of the certificate: computed, with the
   specialization arguments stated (AI, unreviewed); the Hodge-class consequence stays ARG + LIT.
 - (X3) gives length > 72 mod p at every prime tried: X' has other or worse singularities for this member: try the
   next candidate (recorded); if several candidates fail the same way, the node count of section 10.2 is wrong in
   general, which would be a serious problem for sections 10 and 11.
 - (X4) gives 72 mod p (no relation): contradicts section 10.2 (blind-checked twice at random members): then this
   rational member is special in some way, or the earlier runs were wrong: stop and find out which.
 - (X1) fails for all candidates with both W options: the w-part is too special; extend the rule (recorded).
