(i) Formula.  CORRECT, sign right for every m, in particular m = 3, 4, 5.
  My derivation: blow up Sigma in X, E_p = P^(2m-1), D = proper transform of X' = pi^*h - 2 sum E_p, smooth,
  D ∩ E_p = Q_p.  Blow-up formula: pi^*[Z] = [Z~] + sum_p mult_p(Z) [P^m in E_p]; and [P^m].[Z'~] =
  deg PC_p(Z') = mult_p(Z').  Hence Z.Z' = Z~.Z'~ + sum mult_p(Z) mult_p(Z').  Both proper transforms lie in
  D, so Z~.Z'~ = int_D [Z~][Z'~] (pi^*h - 2 sum Q_p) = (Z∩H').(Z'∩H')_X'' - 2 sum_p (PC_p Z . PC_p Z')_Q_p.
  With mult = alpha + beta:   -2(a a' + b b') + (a+b)(a'+b') = -(a-b)(a'-b')   (quadric of dim 2k, k even, m odd)
                              -2(a b' + b a') + (a+b)(a'+b') = +(a-b)(a'-b')   (k odd, m even)
  i.e. Z.Z' = (Z∩H').(Z'∩H') - (-1)^(m-1) sum n_p(Z) n_p(Z').   m = 3: minus, m = 4: plus, m = 5: minus.
  Independent sanity check I did: Z = Z' = P^m in a smooth cubic 2m-fold, 2^m nodes with n = +-1.  The ladder
  gives -1, 3, -5, 11, -21 for m = 1..5, and the top Chern class of the normal bundle (coefficient of h^m in
  (1+h)^(m+1)/(1+3h)) is 3, -5, 11, -21 for m = 2..5.  Agreement in all cases.
  Points to state explicitly when the formula is used: the tangent cone must be taken as a cycle (with
  multiplicities); n_p is defined up to a sign per node but n_p(Z) n_p(Z') is well defined; Z, Z' not inside
  the exceptional locus (automatic).

Implementation (mine, written from the characterisation; t7_dual.py, with t7.m2 for instance generation and
a cross-check):
  With T = kk[z,p,q] and JT = (Jac(F) + (w)) ∩ T = (dF8/dx_i, G_k|w=0), T/JT has Hilbert function
  (1, 9, 33, 57, 42, 12, 1, 0), so S_9 = Jac_9 + ((w)^2)_9.  Hence psi is already forced by psi((w)^2) = 0
  (a part of I^2) and the Griffiths-Dwork rule, and splits as psi(P0 + sum w_l P_l) = Psi0(P0) + sum Psi_l(P_l)
  with   Psi_l(v dF_j|w=0) = (1/6) pi(v) [j = w_l],
         Psi0(v dF_j|w=0) = (1/6) pi(dv/dx_j) [j <= 9] - sum_l Psi_l(v * (w_l-coefficient of dF_j)).
  These are solved as overdetermined linear systems on the degree-7 Macaulay matrix of JT (6435 unknowns,
  15444 equations per right-hand side), all equations are then verified, and the values obtained from
  different factorisations of the same monomial are compared.
Instances: M2-generated (32003; 1, 2), (31991; 1, 2), and one generated in Python (p = 32003, seed 7).
Results, identical in pattern on all 5 instances:
  * dim (T/JT)_6 = 1 (rank 3002 of 3003); pi vanishes on (I_V)_6; dim (T/(JT + I_V))_6 = 1.
  * first-order condition pi(Q A) = 0 for all 165 cubic monomials Q in z,p,q (the others are trivially 0).
  * linear systems: 0 equations violated of 416,988 (Psi_l) and 0 of 694,980 (Psi0); 0 inconsistencies between
    factorisations.  So a functional with the stated properties exists and is unique.
  * E2, Q of w-degree 0 (165 monomials): pi(Q a2 h(z)) = 3 psi(Q A^2) holds for 165 of 165.
    pi(Q h(z)) != 0 for all 165 Q, and the quotient 3 psi(Q A^2)/pi(Q h(z)) is the SAME number for all 165 Q
    and equals a2:   a2 = 2686 (32003,1);  2112 (32003,2);  22849 (31991,1);  6458 (31991,2);  12934 (own).
    With 2*a2: 0 of 165 agree.  With 0: 0 of 165 agree.
  * E2, Q = w_m Q' (135 monomials): psi(w_m Q' A^2) = 0 = pi(w_m Q' g2)/3 for 135 of 135.
  * E2, Q of w-degree >= 2 (64 monomials): both sides vanish by construction (Q A^2 in (w)^2, Q g2 in (w)).
    So the identity holds for all 364 Q; 300 of them are genuine computations.
  * The rest of the characterisation: psi vanishes on every generator*monomial product of (I_V^2)_9 in
    w-degree 0 (0 of 11,187 nonzero) and of w_l (I_V)_8 (0 of 34,749 nonzero); control: psi is nonzero on

Limits: mod p, two primes.  The test shows the algebraic identity for functionals defined by the stated
